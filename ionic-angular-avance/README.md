# Avance Ionic + Angular

## Pasos principales

### 1. Crear proyecto
```bash
ionic start ionic-angular-avance blank --type=angular
cd ionic-angular-avance
```

### 2. Generar páginas
```bash
ionic generate page inicio
ionic generate page detalle
```

### 3. Configurar rutas
Editar `app.routes.ts`.

### 4. Subir a GitHub
```bash
git init
git add .
git commit -m "avance"
git remote add origin TU_REPO
git push -u origin main
```

### 5. Desplegar en Vercel
- Importar repositorio en Vercel.
- Framework: Angular.
- Build command: `npm run build`
- Output: `dist/app`
