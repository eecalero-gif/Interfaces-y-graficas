
# Avance Ionic + Angular

## Comandos usados
```
npm install -g @ionic/cli
ionic start ionic-angular-avance blank --type=angular
ionic generate page inicio
ionic generate page detalle
```

## GitHub
Sube el proyecto con:
```
git init
git add .
git commit -m "avance"
git remote add origin TU_REPO
git push -u origin main
```

## Vercel
1. Importa el repo en Vercel
2. Framework: Angular
3. Build command: `npm run build`
4. Output: `dist`
